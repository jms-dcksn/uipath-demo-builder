# AGENTS.md

## Purpose
This repository provides **demo-builder companion skills** that augment (not replace) the core UiPath skill set for presales work.

Use these assets to help sales engineers quickly shape and build demo-grade, Flow-first UiPath projects that are credible, lightweight, and easy to continue in Studio Web.

## Intent and Positioning
- Treat this repo as a **tailoring layer** on top of official UiPath skills.
- The core UiPath skills remain the source of truth for product mechanics and platform operations.
- These demo-builder skills add orchestration, templates, and guardrails focused on demo storytelling, speed, and repeatability.

## What to Optimize For
- Fast path from customer use case -> buildable demo plan -> working artifacts.
- Demo-grade scope: clear happy path plus one exception path.
- Deterministic behavior for repeatable walkthroughs.
- Outputs that are practical for sales engineering handoff and iteration.

## Working Expectations
- Prefer the planner-led workflow and keep artifacts coherent under `builds/<demo-slug>/`.
- Keep changes concise, practical, and aligned to the existing repository conventions.
- When in doubt, preserve simplicity and demo reliability over production-level complexity.
